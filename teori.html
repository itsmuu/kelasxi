Modul Pembelajaran: Konsep IP Address & Subnetting CIDR

Panduan teori fundamental pengalamatan jaringan komputer untuk kelas Teknik Komputer dan Jaringan (TKJ).

1 IP Address (Alamat IP)

IP Address (Internet Protocol Address) adalah deretan angka biner (atau angka desimal) unik yang diidentifikasikan ke setiap perangkat (seperti PC, Laptop, Smartphone, Router) yang terhubung ke jaringan berbasis protokol TCP/IP.

Analogi Guru: Bayangkan IP Address seperti Alamat Rumah Anda. Tanpa nomor rumah dan nama jalan yang jelas, kurir paket tidak akan bisa mengirimkan barang ke rumah Anda. Begitu pula data di internet tidak akan sampai ke komputer Anda tanpa IP Address.

Pada IPv4, alamat terdiri dari 32 bit biner yang dibagi menjadi 4 bagian (oktet), di mana setiap oktet dipisahkan oleh tanda titik (dot-decimal notation). Contoh: 192.168.10.1.

2 Subnet Mask & Prefix CIDR

Subnet Mask adalah angka 32-bit yang membedakan mana bagian dari IP Address yang berfungsi sebagai Network ID (identitas kelompok jaringan) dan mana yang merupakan Host ID (identitas perangkat individu).

CIDR (Classless Inter-Domain Routing) adalah metode penulisan singkat subnet mask menggunakan tanda garis miring (/) diikuti jumlah bit bernilai 1. Contoh: /24 berarti terdapat 24 bit angka 1 di awal subnet mask.

Analogi Guru: Jika IP Address adalah alamat rumah lengkap, maka Subnet Mask adalah pemisah antara Nama Komplek Perumahan (Network ID) dan Nomor Rumah (Host ID).
Prefix CIDR Subnet Mask (Desimal) Total IP Address
/24 255.255.255.0 256
/25 255.255.255.128 128
/26 255.255.255.192 64
/27 255.255.255.224 32

3 Network Address (IP Network)

Network Address adalah IP pertama dari seluruh rentang alamat dalam satu blok subnet. IP ini digunakan untuk mewakili atau mendefinisikan seluruh grup jaringan tersebut.

  • Sifat Utama: Berada di posisi paling awal dalam blok (contoh: 192.168.1.0 pada /24).
  • Aturan Penting: Network Address TIDAK BISA dipasang/diberikan kepada perangkat host (Komputer, Router, Printer).

4 Broadcast Address (IP Broadcast)

Broadcast Address adalah IP terakhir dari seluruh rentang alamat dalam satu blok subnet. IP ini digunakan untuk mengirimkan paket data ke seluruh perangkat yang ada dalam jaringan tersebut secara bersamaan.

  • Sifat Utama: Berada di posisi paling akhir dalam blok (contoh: 192.168.1.255 pada /24).
  • Aturan Penting: Sama seperti Network Address, IP Broadcast TIDAK BISA dipasang pada perangkat host.

5 Jumlah IP vs Jumlah Host (Usable Host)

Terdapat perbedaan mendasar antara total IP yang tercipta dengan IP yang benar-benar bisa kita pakai untuk perangkat:

A. Jumlah Total IP

Jumlah seluruh alamat IP yang ada di dalam satu blok subnetting.

Rumus: Total IP = 2(32 - CIDR)

Contoh untuk CIDR /26: Total IP = 2(32 - 26) = 26 = 64 IP.

B. Jumlah Host Yang Boleh Digunakan (Usable Host)

Jumlah IP yang benar-benar bisa kita tetapkan ke komputer/laptop. Dikurangi 2 karena IP pertama (Network) dan IP terakhir (Broadcast) dipesan khusus oleh sistem.

Rumus: Usable Host = Total IP - 2

Contoh untuk CIDR /26: Usable Host = 64 - 2 = 62 Host.

6 Blok Subnet (Subnet Block)

Blok Subnet adalah ukuran kelipatan pembagian jaringan dalam satu rentang IP Address. Blok subnet menentukan di mana jaringan dimulai, berpindah, dan berakhir.

Rumus Blok Subnet = 256 - (Nilai Oktet Terakhir Subnet Mask)

Studi Kasus Ringkas: Hitung parameter subnetting dari IP 192.168.1.50/26!

  1. Subnet Mask /26: 255.255.255.192
  2. Hitung Blok Subnet: 256 - 192 = 64.
  3. Daftar Kelipatan Blok: 0, 64, 128, 192.
  4. Posisi IP 192.168.1.50: Berada di antara 0 dan 64 (Blok Ke-1: 0 sampai 63).
Parameter Hasil Perhitungan
Network Address 192.168.1.0 (IP Pertama)
Broadcast Address 192.168.1.63 (IP Terakhir sebelum 64)
Range IP Host 192.168.1.1 s/d 192.168.1.62
Total Host Boleh Pakai 62 Host

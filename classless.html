Apa itu IP Address?

Bayangkan setiap komputer di jaringan itu seperti rumah, dan IP Address adalah alamat rumah tersebut. Agar data bisa sampai ke tujuan yang benar, setiap perangkat harus punya alamat yang unik.

IPv4 terdiri dari 32 bit (angka biner 0 dan 1), dibagi menjadi 4 kelompok yang disebut oktet. Setiap oktet berisi 8 bit.

// bentuk biner
11000000.10101000.00000001.00000001
// bentuk desimal (yang biasa kita lihat)
192.168.1.1

Kenapa nilai maksimal tiap oktet 255? Karena 8 bit membentuk kombinasi dari 00000000 (=0) sampai 11111111 (=255) — total 256 kemungkinan nilai.

02

Kenapa Perlu Dibagi ke Dalam "Kelas"?

Di awal perkembangan internet, insinyur jaringan perlu cara otomatis untuk membagi jaringan besar dan kecil. Maka dibuatlah sistem Class — kategori ukuran jaringan.

Analogi kompleks perumahan:
Class A = kompleks perumahan raksasa (1 kota penuh) · Class B = kompleks sedang (1 kecamatan) · Class C = kompleks kecil (1 RT/RW)

Setiap IP address dibagi menjadi 2 bagian:

Network ID — "kompleks perumahan mana" Host ID — "nomor rumah keberapa"
03

Cara Komputer Menentukan Kelas

Komputer melihat bit pertama pada oktet pertama untuk menentukan kelasnya. Pola bit ini disebut bit identifier.

KelasPola Bit AwalArtinya
A0.......Bit pertama = 0
B10......2 bit pertama = 10
C110.....3 bit pertama = 110
D1110....4 bit pertama = 1110
E1111....4 bit pertama = 1111

Contoh perhitungan Class A

Bit pertama harus 0, sisanya bebas: 00000001 sampai 01111110 → diubah ke desimal = 1 sampai 126.

Contoh perhitungan Class B

2 bit pertama harus 10: 10000000 sampai 10111111 → diubah ke desimal = 128 sampai 191.

05

Kenapa Host Class C Maksimal 254, Bukan 256?

Dari 256 kemungkinan (0–255) di oktet Host, ada 2 alamat yang tidak boleh dipakai untuk perangkat:

1. Alamat terkecil (semua bit host = 0) → jadi Network Address, contoh 192.168.1.0
2. Alamat terbesar (semua bit host = 1) → jadi Broadcast Address, contoh 192.168.1.255

Jadi host yang bisa dipakai: 192.168.1.1 sampai 192.168.1.254 = 254 host.

Jumlah Host = 2ⁿ − 2
n = jumlah bit host  |  Class C: 2⁸−2 = 254  ·  Class B: 2¹⁶−2 = 65.534  ·  Class A: 2²⁴−2 = 16.777.214

08

Kelebihan & Kekurangan Classful

Kelebihan: Sederhana, mudah dipahami, cocok untuk pembelajaran dasar konsep IP addressing.

Kekurangan: Boros alamat IP — misalnya Class C hanya menyediakan 254 host meski kebutuhan bisa lebih sedikit atau lebih banyak. Tidak fleksibel dibanding metode modern CIDR (Classless Inter-Domain Routing) yang digunakan saat ini.

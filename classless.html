Classless IP Address (CIDR)

Memahami konsep pengalamatan IP fleksibel tanpa kelas dan perhitungan Blok Subnet.

1. Pengertian Sederhana

Classless IP (atau dikenal sebagai CIDR - Classless Inter-Domain Routing) adalah metode pengalamatan IPv4 tanpa membagi-bagi IP ke dalam kelas kaku (Kelas A, B, atau C). Pembagian jaringan dilakukan secara dinamis sesuai kebutuhan spesifik perangkat.

💡 Analogi Sederhana: Paket Ukuran Baju

Classful (Sistem Lama): Seperti toko yang hanya menjual baju ukuran S (254 orang), M (65.000 orang), dan L (16 juta orang). Jika butuh baju untuk 300 orang, Anda terpaksa membeli ukuran M, sehingga 64.700 baju sisanya terbuang sia-sia.

Classless (Sistem Modern): Toko baju ini memungkinkan Anda memesan ukuran baju yang pas dan fleksibel (misalnya khusus untuk 300, 50, atau 12 orang saja) tanpa ada alokasi yang terbuang.

2. Notasi Prefix (Slash /)

Dalam Classless IP, pembatas kelas kaku dihapus total. Pembagian alokasi jaringan ditentukan oleh Subnet Mask yang ditulis dalam bentuk Notasi Prefix (Slash /), contohnya: 192.168.1.0/26.

Angka setelah garis miring (/26) menunjukkan jumlah bit 1 pada Subnet Mask (dari total 32 bit IPv4).

Contoh Pembacaan Prefix /26:

  • Subnet Mask Biner: 11111111.11111111.11111111.11000000 (26 bit angka 1)
  • Subnet Mask Desimal: 255.255.255.192
  • Sisa Bit Host (h): 32 - 26 = 6 bit (diwakili bit angka 0)

3. Rumus Perhitungan Classless IP

Untuk menghitung kapasitas alamat dan pembagian blok subnet pada Classless IP, gunakan acuan sisa bit host (h = 32 - prefix):

1. Sisa Bit Host (h) = Total Bit IPv4 (32) - Nilai Prefix
2. Total IP Address = 2h
3. Jumlah IP Host Usable = (2h) - 2
4. Blok Subnet (Lompatan) = 256 - Nilai Oktet Aktif Subnet Mask

Mengapa IP Host tetap dikurangi 2?
Sama seperti prinsip pengalamatan dasar, 2 alamat IP disisihkan untuk:

  • IP Pertama (Paling Awal): Digunakan sebagai Network ID.
  • IP Terakhir (Paling Akhir): Digunakan sebagai Broadcast ID.

Langkah Perhitungan Contoh Kasus 192.168.10.0/27:

  1. Menghitung Bit Host (h):
    • h = 32 - 27 = 5 bit host
  2. Menghitung Total IP & Host Usable:
    • Total IP = 25 = 32 IP Address
    • IP Host Usable = 32 - 2 = 30 Host yang dapat dipakai perangkat
  3. Menentukan Subnet Mask & Blok Subnet (Lompatan):
    • Subnet Mask Desimal = 255.255.255.224 (Oktet aktif = 224)
    • Blok Subnet = 256 - 224 = 32 (Lompatan kelipatan 32: 0, 32, 64, 96, dst.)

4. Contoh Pembagian Subnet (Studi Kasus 192.168.10.0/27)

Berdasarkan hasil perhitungan blok subnet dengan kelipatan 32, berikut adalah pembagian jangkauan alamat yang terbentuk:

5. Perbandingan Classful vs Classless IP

Berikut adalah poin-poin perbedaan utama antara kedua sistem pengalamatan IPv4:

Karakteristik Classful IP Classless IP (CIDR)
Pembagian Kelas Terikat Kelas A, B, C, D, E Tidak ada kelas (Bebas/Fleksibel)
Subnet Mask Tetap (/8, /16, /24) Fleksibel (/8 s/d /30)
Efisiensi Alokasi Boros (Banyak IP terbuang) Sangat Efisien (Sesuai kebutuhan)
Notasi Penulisan Subnet Mask Desimal Full Notasi Prefix / Slash (/X)

📌 Rangkuman Penting

  • Classless IP (CIDR) menghapus batasan kelas kaku demi efisiensi penggunaan alamat IPv4.
  • Notasi Prefix (/X) menentukan jumlah bit 1 pada Subnet Mask.
  • Total IP dihitung dengan 2h dan Host Usable dihitung dengan 2h - 2.
  • Blok Subnet (lompatan) dihitung menggunakan rumus 256 - Nilai Oktet Aktif Subnet Mask.

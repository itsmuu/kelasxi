Classless IP Address (CIDR)

Memahami konsep pengalamatan IP fleksibel tanpa kelas dan perhitungan Blok Subnet.

1. Pengertian Sederhana

Classless IP (atau dikenal juga sebagai CIDR - Classless Inter-Domain Routing) adalah metode pengalamatan IPv4 tanpa membagi-bagi IP ke dalam kelas kaku (Kelas A, B, atau C).

💡 Analogi Sederhana: Paket Ukuran Baju

Classful (Sistem Lama): Seperti toko baju yang hanya memiliki 3 ukuran kaku: S (maks. 254 orang), M (maks. 65.000 orang), dan L (maks. 16 juta orang). Jika perusahaan membutuhkan baju untuk 500 orang, mereka terpaksa mengambil ukuran M. Akibatnya, 64.500 baju terbuang sia-sia.

Classless (Sistem Modern): Toko baju ini memungkinkan memesan ukuran yang pas dan sesuai kebutuhan (misal khusus untuk 500, 100, atau 30 orang saja). Tidak ada alokasi yang terbuang.

2. Mengapa Classless IP Dibutuhkan?

Pengalamatan sistem Classful lama menimbulkan beberapa masalah fatal di era internet modern:

  • Pemborosan Alokasi IP: Banyak IP tersisa yang terbuang dalam satu jaringan kelas.
  • Krisis Kelangkaan IPv4: Stok alokasi IPv4 global yang sangat terbatas cepat habis.
  • Tabel Routing Membengkak: Router internet harus menyimpan jutaan baris rute kelas terpisah.

Sistem CIDR/Classless IP resmi diperkenalkan pada tahun 1993 untuk mengatasi masalah krisis alokasi IP tersebut.

3. Notasi Prefix (Slash /)

Dalam Classless IP, pembatas kelas dihapus total. Pembagian jaringan ditentukan oleh Subnet Mask yang dinyatakan dalam Notasi Prefix (Slash /), contohnya: 192.168.1.0/26.

Angka setelah garis miring (/26) menunjukkan jumlah bit 1 pada Subnet Mask (dari total 32 bit IPv4).

Contoh Pembacaan /26:

  • Subnet Mask Biner: 11111111.11111111.11111111.11000000 (26 bit angka 1)
  • Subnet Mask Desimal: 255.255.255.192
  • Sisa bit 0 untuk Host ID (h): 32 - 26 = 6 bit

4. Rumus Perhitungan & Blok Subnet

Gunakan rumus dasar berikut untuk menganalisis alokasi Classless IP berdasarkan sisa bit host (h = 32 - prefix):

Sisa Bit Host (h) = 32 - Prefix
Total IP = 2h
Jumlah Host Usable = (2h) - 2
Blok Subnet (Lompatan) = 256 - Nilai Oktet Aktif Subnet Mask

Blok Subnet adalah jarak interval/lompatan dari satu jangkauan Network ID ke Network ID berikutnya.

Contoh Kasus: Hitung Alokasi 192.168.10.0/27

  1. Cari Bit Host (h):
    h = 32 - 27 = 5 bit
  2. Hitung Total IP & Host Usable:
    Total IP = 25 = 32 IP | Host Usable = 32 - 2 = 30 Host
  3. Tentukan Subnet Mask:
    Desimal = 255.255.255.224 (Oktet terakhir = 224)
  4. Hitung Blok Subnet (Lompatan):
    Blok Subnet = 256 - 224 = 32 (Kelipatan 32: 0, 32, 64, 96, 128, dst.)

5. Perbandingan Classful vs Classless IP

Karakteristik Classful IP Classless IP (CIDR)
Pembagian Kelas Terikat Kelas A, B, C, D, E Tidak ada kelas (Bebas)
Subnet Mask Tetap / Default (/8, /16, /24) Fleksibel (/8 s/d /30)
Efisiensi IP Boros (Banyak IP tidak terpakai) Sangat Efisien (Sesuai kebutuhan)
Notasi Penulisan Subnet Mask Desimal Notasi Prefix / Slash (/X)
Ukuran Blok Subnet Kaku / Tetap (256, 65536, dst.) Dinamis sesuai Prefix

📌 Rangkuman Penting

  • Classless IP (CIDR) menghilangkan batasan kelas kaku demi efisiensi stok IPv4.
  • Notasi Prefix (/X) menentukan berapa banyak bit 1 pada Subnet Mask.
  • Semakin besar angka prefix (misal /30), semakin sedikit jumlah host yang didapat.
  • Blok Subnet adalah nilai lompatan antar Network ID yang dihitung dari 256 - nilai_oktet_aktif.

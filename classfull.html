Classful IP Addressing (IPv4)

Memahami arsitektur pengalamatan IP berbasis kelas kaku beserta perhitungan kapasitasnya.

1. Pengertian Sederhana

Classful IP Addressing adalah metode pembagian alamat IPv4 (32-bit) ke dalam 5 kelas terpisah (Kelas A, B, C, D, dan E) berdasarkan aturan nilai tetap bit pertama pada oktet pertamanya. Setiap IP dibagi secara kaku menjadi bagian Network ID (wilayah jaringan) dan Host ID (identitas perangkat).

💡 Analogi Sederhana: Ukuran Kavling Perumahan

Bayangkan pengembang perumahan hanya menyediakan 3 jenis ukuran lahan kaku:

Kelas A (Ukuran Raksasa): Menyediakan lahan jaringan kecil, tetapi muat hingga jutaan rumah (host) di dalamnya.

Kelas B (Ukuran Sedang): Menyediakan lahan menengah yang muat sekitar 65.000 rumah.

Kelas C (Ukuran Perumahan Kecil): Menyediakan banyak lahan jaringan, tetapi hanya muat maksimal 254 rumah saja.

2. Pembagian Kelas IP Address

Berikut adalah tabel acuan utama pembagian kelas dalam sistem Classful IP Addressing:

Kelas Rentang Oktet Pertama Default Subnet Mask Notasi Prefix Komposisi (Net : Host) Peruntukan
Kelas A 1 - 126 255.0.0.0 /8 Net . Host . Host . Host Jaringan Skala Raksasa/ISP
Kelas B 128 - 191 255.255.0.0 /16 Net . Net . Host . Host Skala Menengah - Besar
Kelas C 192 - 223 255.255.255.0 /24 Net . Net . Net . Host Jaringan Lokal (LAN) / Kecil
Kelas D 224 - 239 Tidak ada Tidak ada Multicast Address Komunikasi Multicasting
Kelas E 240 - 254 Tidak ada Tidak ada Experimental Riset & Masa Depan

* Catatan: Alamat 127.x.x.x dilewati dari Kelas A karena dialokasikan khusus sebagai Loopback Address / Localhost untuk pengujian koneksi lokal perangkat.

3. Cara Menghitung Jumlah IP & Jumlah IP Host

Untuk mengetahui jumlah alamat yang dapat digunakan dalam suatu kelas IP, kita menggunakan acuan jumlah bit host (n) yang bernilai 0 pada Default Subnet Mask.

1. Jumlah Bit Host (n) = Total Bit IPv4 (32) - Jumlah Bit Network
2. Jumlah Total IP = 2n
3. Jumlah IP Host (Usable IP) = (2n) - 2

Mengapa dikurangi 2?
Sebab 2 alamat IP wajib dialokasikan untuk fungsi khusus:

  • IP Pertama: Dipakai sebagai Network ID (Identitas alamat jaringan).
  • IP Terakhir: Dipakai sebagai Broadcast ID (Alamat pengiriman pesan ke seluruh host).

Langkah-Langkah Perhitungan Tiap Kelas:

  1. Menghitung Kelas C (Default Prefix /24 atau Subnet Mask 255.255.255.0):
    • Bit Host (n) = 32 bit - 24 bit network = 8 bit host
    • Total IP = 28 = 256 IP Address
    • IP Host Usable = 256 - 2 = 254 Host yang dapat dipakai perangkat
  2. Menghitung Kelas B (Default Prefix /16 atau Subnet Mask 255.255.0.0):
    • Bit Host (n) = 32 bit - 16 bit network = 16 bit host
    • Total IP = 216 = 65.536 IP Address
    • IP Host Usable = 65.536 - 2 = 65.534 Host
  3. Menghitung Kelas A (Default Prefix /8 atau Subnet Mask 255.0.0.0):
    • Bit Host (n) = 32 bit - 8 bit network = 24 bit host
    • Total IP = 224 = 16.777.216 IP Address
    • IP Host Usable = 16.777.216 - 2 = 16.777.214 Host

4. Contoh Studi Kasus Penggunaan Classful IP

Misalkan diberikan sebuah IP Address Kelas C: 192.168.1.50 dengan Default Subnet Mask 255.255.255.0.

Parameter Hasil Perhitungan Keterangan
Network ID 192.168.1.0 Alamat IP paling awal pada subnet
Broadcast ID 192.168.1.255 Alamat IP paling akhir pada subnet
Rentang IP Host Usable 192.168.1.1 s/d 192.168.1.254 IP yang bisa terpasang di PC/Laptop
Kapasitas Perangkat 254 Perangkat Host Hasil perhitungan (28) - 2

5. Kekurangan Utama Classful IP Addressing

Meskipun mudah diterapkan, sistem pengalamatan berbasis kelas memiliki kelemahan fatal:

  • Innefisiensi Alokasi & Pemborosan IP: Jika kantor membutuhkan 300 IP, kelas C (254 host) tidak memadai. Kantor terpaksa memilih Kelas B (65.534 IP), yang berarti ada 65.000+ IP terbuang sia-sia.
  • Krisis Kelangkaan IPv4: Terbuangnya alokasi IP di Kelas A dan B mempercepat habisnya ketersediaan IPv4 di dunia.

Oleh karena itu, dibuatlah metode Classless Addressing (CIDR) untuk menggantikan Classful secara penuh.

📌 Rangkuman Penting

  • Classful IP membagi alamat IPv4 secara kaku menjadi Kelas A, B, C, D, dan E.
  • Total IP dihitung dengan rumus 2n (di mana n adalah jumlah bit host).
  • IP Host (Usable) dihitung dengan 2n - 2 karena 2 IP disisihkan untuk Network ID dan Broadcast ID.
  • Classful IP kini sudah tidak lagi digunakan secara fleksibel karena masalah pemborosan alokasi IP.
